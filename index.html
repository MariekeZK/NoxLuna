⚠️ iCloud is helaas niet gratis beschikbaar voor webapps — dat vereist een Apple Developer-account (€99/jaar).

Het beste gratis alternatief is Firebase (Google). Gratis plan: 1 GB opslag, geen verloopdatum, werkt op alle apparaten.
📱 Lokale opslag — data staat alleen op dit apparaat.
📖 firebase.google.com → gratis project aanmaken → Firestore Database inschakelen → Project Settings → jouw config invullen.
